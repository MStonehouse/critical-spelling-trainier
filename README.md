# Spelling Recall Trainer

Standalone spelling-memory web app.

## Features
- Brief visual word exposure, then hidden recall
- Large curated commonly-misspelled-word library
- Adjustable display time
- Difficulty and word-length filters
- Mixed / Weak Words / Mostly New modes
- Missed words are weighted to return more often
- First-try accuracy, streaks, and weak-word tracking
- Browser-local persistent stats

Open `index.html` directly, or upload it to GitHub Pages.
